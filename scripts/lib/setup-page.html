Set up gork

gork is a Discord bot. This page gets it running. You do a few small things (click a button, copy a code, paste it here) and setup does the rest. It takes about 10 minutes. Your tokens go only to Discord and Cloudflare, and into .env on this computer.

This setup page has closed. Run npm run setup again, or use the newest setup tab.

If setup stopped (you pressed Ctrl+C, or it sat unused for 30 minutes), it took back anything it had made and not kept. Nothing on this page works until setup is back. This page keeps checking and clears this message if setup comes back.

How should gork pay for its AI?
More about Free

The allowance is about 10,000 “neurons” a day (Cloudflare's unit of AI work) and starts again at 00:00 UTC. When it runs out, gork stops answering until then. On Workers Paid, each 1,000 neurons past it costs $0.011.

Advanced: personality, pings, time zone and budget

Left alone, gork uses the default personality, pings no one and uses this browser's time zone. With credits, it stops for the day at $0.50.

What should gork be like?

You already have a custom personality (personas/custom.md): saving replaces it.

Say who gork is, how it talks (short or long, slang, emoji) and what its humor is like. A few lines is enough. Write {name} wherever gork's name should go. Don't repeat gork's built-in rules (accuracy, safety, length): it adds those itself.

One extra instruction that gork follows on some replies, for example “After the answer, add one short jab in character.”

    Make the gork bot

    Open the Discord Developer Portal

    1. In the page that opens (log in to Discord if it asks), name the app gork and click Create.
    2. In the menu on the left click Bot. Click Reset Token (Discord may ask for a code from your phone), then click Copy.
    3. Come back to this tab and paste the token below.

    The token is like a password for the bot. It goes only to Discord, and into .env on this computer. This page never shows it back.

    Checking with Discord…

      Add gork to your server

      Click the button, choose your server in the list, and click Authorize. (You need permission to manage that server.)

      Add gork to a server

      Waiting for gork to join. Setup checks every few seconds and shows your server here.

      Which server should gork answer in?

      To use gork in more than one server later, add their IDs to GUILD_IDS in the .env file.

      gork joined but isn't listed? Enter the server ID yourself

      In Discord open Settings, Advanced, and turn on Developer Mode. Then right-click your server's icon and choose Copy Server ID.

      Optional: make the bot private

      Anyone with the bot's invite link can add it to their own server. gork ignores servers it isn't set up for, so this only keeps things tidy.

      1. In the Developer Portal click Installation in the menu on the left. Under Install Link choose None, then click Save Changes. (Discord won't turn Public Bot off while an install link is set.)
      2. Click Bot in the menu on the left. Turn Public Bot off, then click Save Changes.

      Connect Cloudflare

      Finish step 2 first.

        Cloudflare runs the AI. No account yet? Make a free one and confirm your email, then come back.

        Create a one-time setup token

        Create the setup token

        1. Cloudflare opens with a form already filled in. Choose your account if it asks.
        2. Set the token's expiry (“TTL”) so that it ends 1 hour from now. Then it deletes itself even if something goes wrong.
        3. Click Continue, then Create Token.
        4. Copy the long secret Cloudflare shows (it is shown only once) and paste it below.

        This setup token can only create gork's own two keys. Setup deletes it at the end.

        More about the admin key

        It can only manage AI Gateway. It is saved in .env on this computer and never goes inside gork's container. If you turn this off, the key expires after an hour, and npm run up stops working until you put a new CF_ADMIN_TOKEN in .env.

        Setting up Cloudflare. This takes about half a minute.

          Which Cloudflare account?

          Account

          You already have an AI Gateway called “”

          Using it for gork changes its settings: only gork's key can use it, Cloudflare keeps no copy of what passes through, and it gets a daily spending limit. Nothing changes unless you say so.

          More: its settings now, and gork's

            gork sets authentication on, zero data retention, a daily spending limit, and billing.

            Letters, digits and hyphens only. Setup leaves the one you have alone and makes a new one.

            What gork's key can do

              gork's key works, but there are no credits yet. Credits pay for the AI. Open the Cloudflare page, click Manage, then Top-up credits. The minimum top-up is $10, which lasts a long time at gork's usage.

              Leave auto top-up off. Then the balance is the most that a stolen key could ever spend.

              Open Cloudflare credits

              If you carry on, gork can't answer until you add credits. npm run doctor checks again later.

              Keys from an earlier setup are still active in your Cloudflare account:

                The new settings don't use them. If a gork you already run still does, it will stop working once they are revoked.

                The button saves your settings in a file called .env in the gork folder (only your account can read it), then deletes the one-time setup token and checks that it no longer works.

                Saving your settings…

                    Last step: start gork. Docker or Podman must be running. The first start downloads gork's image, which is quick. If it can't be downloaded, gork is built on this computer instead, which takes roughly 15 to 30 minutes (longer on a Raspberry Pi).

                    gork runs in a container, so it needs Docker or Podman with Compose. On Windows and Mac the easy way to get them is Docker Desktop or Podman Desktop; on Linux, Docker Engine or Podman is enough. Install one if you have neither, start it, wait until it says it is running, then press Retry.
